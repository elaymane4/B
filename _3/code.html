مفعّل بالخلفية
volume_down

قاعدة عمل الزر الفيزيائي للمكفوفين

touch_app
1. الضغط المستمر (Hold): يبدأ المساعد "بصير" في الاستماع فوراً مع اهتزاز ملموس (Haptic buzz) وصوت نغمة بدء.
front_hand
2. رفع اليد (Release): يتوقف الاستماع فوراً ويتم تنفيذ الأمر الصوتي مباشرة وإعلان النتيجة بصوت واضح.
screen_lock_portrait
3. أثناء قفل الشاشة (Screen Off): يعمل الزر عبر خدمة إمكانية الوصول في أندرويد دون الحاجة لفتح قفل الشاشة.
volume_down
4. خفض مستوى الصوت العادي: إذا لم يتم نطق أمر صوتي، أو عند استمرار الضغط في وضع الوسائط، يتم خفض درجة الصوت تدريجياً.
sensors
